¿Cómo configurar la API Key de Claude en Render para Producción?

Para que tu servidor en la nube utilice la llave de Anthropic Claude como prioridad número uno con los $200 USD de crédito, solo debes añadir la variable de entorno en tu panel de Render siguiendo estos 4 sencillos pasos:

Paso 1. Ingresar a Render
Entra a dashboard.render.com y haz clic en tu Web Service touchid-backend.
Paso 2. Pestaña Environment
En el menú lateral izquierdo de tu servicio, pulsa en la opción Environment.
Paso 3. Añadir Variable
Haz clic en Add Environment Variable y pega los datos que figuran debajo.
Paso 4. Guardar Cambios
Pulsa Save Changes. Render reiniciará y compilará con Claude activo en ~60 seg.

ANTHROPIC_API_KEY
