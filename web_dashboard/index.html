Configuración del Entorno de Red

Establece las claves de la API de Gemini y las credenciales del proyecto de Firebase para habilitar la sincronización en tiempo real.

Si dejas el JSON vacío, el dashboard intentará inicializar Firebase usando el Project ID predeterminado, pero es recomendable insertar las credenciales completas del SDK web de Firebase para mayor estabilidad.

Guía de Configuración Rápida

1

Configurar Firestore

En tu consola de Firebase en `jbac-examen-parcial-2026`, crea una base de datos de Firestore en modo de prueba.

2

Registrar Extensión y Web

Usa las mismas credenciales de Firebase en la extensión de Chrome y en este panel web.

3

Modo Compañero Activado

Abre la app de Flutter en tu celular. Al estar conectada a la misma base de datos Firestore, mostrará instantáneamente las respuestas de las preguntas que raspes en tu PC.
