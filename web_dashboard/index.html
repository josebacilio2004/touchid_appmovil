¿Cómo funciona la venta?

1

Generar el código

Elige el paquete de créditos (ej. 50 créditos) y presiona Generar. Se guardará de manera segura en tu base de datos Firestore.

2

Vender y entregar

Copia el código de licencia prepago y envíaselo a tu cliente por WhatsApp, Telegram o correo tras confirmar su pago.

3

Canje automático

El cliente ingresa el código en los ajustes de su aplicación o extensión. El servidor de Render lo validará, cargará los créditos en su ID de Cliente y marcará la licencia como canjeada.
